## 3.2 - Methods - Operational

### 3.2.1 -GetCombos

The `GetCombos` method retrieves valid carrier and service level combinations for a specific client from the database and displays the results in a data grid on the form.

#### Signature

```cs
private void GetCombos()
```

#### Breakdown

* Define SQL Query:
	* Specifies a stored procedure that expects a single parameter: the client identifier.
	* The procedure is responsible for returning all valid carrier/service combinations for that client.

```cs
string query = "EXECUTE [TCAR_Get_Combos] @Client";
```

* Prepare DataTable:
	* A temporary in-memory structure used to hold the results returned from the SQL query.

```cs
DataTable dataTable = new DataTable();
```

* Establish SQL Connection:
	* Opens a secure connection to the database using the predefined connection string.

```cs
using (SqlConnection conn = new SqlConnection(connectionString))
{
    conn.Open();
```

* Set SQL Command and Parameters:
	* Prepares the SQL command with the client parameter, sourced from the `passedClient` field that was set externally.

```cs
using (SqlCommand cmd = new SqlCommand(query, conn))
{
    cmd.Parameters.AddWithValue("@Client", passedClient);
```

* Execute Reader & Load Results:
	* Executes the command and reads the results using a `SqlDataReader`.
	* The `DataTable` is filled with this data for later binding.

```cs
SqlDataReader reader = cmd.ExecuteReader();
dataTable.Load(reader);
```

* Bind Results to Data Grid:
	* Binds the populated table to the UI data grid so that the user can see the carrier combinations.
	* Refreshes the control to ensure it's visually updated.

```cs
dgCarrier.DataSource = dataTable;
dgCarrier.Refresh();
```

* Error Handling:
	* Catches and logs any errors that occur during the database interaction.
	* Displays a custom error message to the user and logs the failure for auditing/debugging.

```cs
catch (Exception ex)
{
    messageBox.ShowDefError("117", $"\n{ex.Message}");
    SessionMaintenance.LogBook("ERROR", "[GetCombos]", "[PopulateDataGrid]", $"FAILED: Code 117 ( {ex.Message} )");
}
```

#### Summary

The `GetCombos` method serves as the data retrieval backbone of the `CarrierCombos` form. It securely connects to the database, retrieves carrier/service combinations for a specific client, and presents the data in a user-friendly format. Any errors encountered during the process are gracefully handled and logged.

```cs
// Get Carrier Combos --------------------------------------------------------------------------------
        private void GetCombos()
        {
            string query = "EXECUTE [TCAR_Get_Combos] @Client";

            DataTable dataTable = new DataTable();

            try
            {
                // Start SQL
                using (SqlConnection conn = new SqlConnection(connectionString))
                {
                    conn.Open(); // Open SQL Connection

                    using (SqlCommand cmd = new SqlCommand(query, conn))
                    {
                        // Set Parameters
                        cmd.Parameters.AddWithValue("@Client", passedClient);

                        // Execute Query
                        SqlDataReader reader = cmd.ExecuteReader();

                        // Populate DataTable From Reader
                        dataTable.Load(reader);
                    }

                    conn.Close(); // Close SQL Connection

                    // Populate Data Grid
                    dgCarrier.DataSource = dataTable;
                    dgCarrier.Refresh();
                }
            }
            catch (Exception ex) // Catch Errors
            {
                CustomMessageBox messageBox = new CustomMessageBox();
                messageBox.ShowDefError("117", $"\n{ex.Message}");
                SessionMaintenance.LogBook("ERROR", "[GetCombos]", "[PopulateDataGrid]", $"FAILED: Code 117 ( {ex.Message} )");
            }
        }
```

## 3.3 - Methods - Environmental

### 3.3.1 -Close Button

These methods manage visual feedback when the mouse interacts with the `btnClose` control. Specifically, they provide a consistent hover effect that helps users understand the button is interactive and ready to be clicked — contributing to a polished and intuitive UI.

#### Signatures

```cs
private void btnClose_MouseEnter(object sender, EventArgs e)
private void btnClose_MouseLeave(object sender, EventArgs e)
```

#### Parameters:

* `sender`(`object`): the source of the event (here, always `btnClose`).
* `e`(`EventArgs`): standard event args, not directly used in this method.

#### Step-by-Step Breakdown

* `btnExit_MouseEnter`
	* Triggered when the cursor enters the Close button’s bounds.
	* Calls `SessionMaintenance.ButtonEnter()` to apply hover styling such as background and/or text color changes.

* `btnExit_MouseLeave`
	* Triggered when the cursor leaves the button area.
	* Calls `SessionMaintenance.ButtonLeave()` to revert the button to its default styling.

#### Summary

These handlers provide a consistent and responsive hover effect for the `btnClose` button using shared methods from `SessionMaintenance`. 

```cs
        // Close Button -----------------------------------------------------
        private void btnClose_MouseEnter(object sender, EventArgs e)
        {
            SessionMaintenance.ButtonEnter(btnClose);
        }

        private void btnClose_MouseLeave(object sender, EventArgs e)
        {
            SessionMaintenance.ButtonLeave(btnClose);
        }
```
